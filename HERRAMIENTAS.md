## 🛠️ Herramientas

### Organización
| Herramienta | Para qué |
|---|---|
| **GitHub Projects** | Tablero de tareas (reemplaza a Jira/Trello) |
| **GitHub Issues** | Cada tarea, bug o idea concreta |
| **GitHub Discussions** | Ideas de proyectos nuevos y charlas que no son tareas |
| **Grupo de WhatsApp** | Avisos rápidos y coordinar. Lo importante se pasa a GitHub |

### Programar
| Herramienta | Para qué |
|---|---|
| **VS Code** | Editor. Extensiones: *Laravel*, *PHP Intelephense*, *Tailwind CSS IntelliSense*, *GitLens* |
| **Git** | Control de versiones (ver ramas y PRs en la [guía](GUIA.md#2-git-ramas-commits-y-prs)) |
| **PHP 8.4 + Composer** | Correr Laravel e instalar dependencias de PHP |
| **Node.js + npm** | Compilar Tailwind/JS con Vite |
| **Laravel Breeze** | Login, registro y recuperar contraseña ya hechos |
| **Pest** | Tests |
| **Claude Code** | Asistente de IA para programar y organizar |

### Diseño
| Herramienta | Para qué |
|---|---|
| **Figma** o **Excalidraw** | Bocetos de pantallas |
| **Canva** | Material rápido para el cliente (logos simples, imágenes para redes) |
| **Google Fonts** | Tipografías |
| **Squoosh** (squoosh.app) | Pasar imágenes a WebP y achicarlas |

### Publicar y mantener
| Herramienta | Para qué |
|---|---|
| **Render** | Hosting con Docker (plan gratis para empezar) |
| **PostgreSQL** (Aiven / Render) | Base de datos de producción |
| **Mailtrap** | Probar mails en desarrollo sin mandarlos de verdad |
| **Brevo** o **Resend** | Mandar mails reales en producción (tienen plan gratis) |
| **NIC Argentina** | Registrar dominios `.com.ar` (a nombre del cliente) |
| **Google Search Console** | Que Google indexe la web |
| **UptimeRobot** | Aviso si la web se cae |
| **MercadoPago** | Cobros online, si el proyecto lo necesita |

## 🔑 Cuentas y accesos

- Cada uno usa **su propia cuenta** en cada herramienta. No compartimos contraseñas por WhatsApp.
- Las cuentas del cliente (dominio, Google Business, MercadoPago) se crean **a nombre del cliente**; nosotros pedimos acceso como colaboradores.
- Las claves de producción solo se cargan en Render; si alguien las necesita, se pasan por un canal privado y se cambian si se filtran.
